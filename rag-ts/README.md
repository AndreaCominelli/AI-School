# RAG Pipeline with Local Vector DB

A small Retrieval-Augmented Generation (RAG) project that uses a local vector database to search document chunks and an LLM to produce contextualized answers.

> **Note:** for now the project can only be run directly on the host with Node.js. A containerized version (Docker or similar) is not available yet.

## How it works

The project follows a RAG pipeline with **contextual retrieval**:

1. **Contextual chunks.** Each chunk is enriched with the context of the PDF it comes from. For simplicity, the PDF context is taken from the first sentence of the document, since it is often the title.
2. **Hybrid search.** The query is run both as a vector search against the local vector DB and through the BM25 ranking function.
3. **Rank fusion.** The two result lists are merged using Reciprocal Rank Fusion (RRF).
4. **Reranking.** A reranking model reorders the fused results.
5. **Top results.** Only the 3 most similar documents are kept.
6. **Answer generation.** The top 3 documents are passed to the LLM together with the original query to obtain a contextualized answer.

Claude is used as the LLM, and Voyage AI is used to create the embeddings.

## Requirements

- Node.js **25 or higher**
- npm
- An Anthropic API key
- A Voyage AI API key

## Installation

```bash
npm i
```

## Environment variables

The following environment variables must be set before running the project:

```dotenv
# Anthropic SDK
ANTHROPIC_API_KEY=   # API key for the Anthropic SDK
ANTHROPIC_MODEL=     # Claude model to use

# Voyage AI SDK
VOYAGE_API_KEY=      # API key for the Voyage AI SDK
VOYAGE_MODEL=        # Voyage AI model used to create the embeddings
```

## Using the RAG on your own documents

1. Add the PDFs you want to analyze to `data/papers`.
2. Convert the PDFs into JSON documents:

   ```bash
   npm run convert
   ```

3. Create the local vector DB and run queries:

   ```bash
   npm run infer
   ```

   If the vector DB does not exist yet, it is created in `data/document_embeddings`.

## Evaluating the RAG quality

1. Create an evaluation dataset:

   ```bash
   npm run create-dataset
   ```

   This generates a JSON document containing a set of evaluation samples taken from the database. Each sample contains:

   - **question**: a question generated by the model
   - **chunkId**: the ID of the chunk that answers the question, built by appending paper + page + chunkId
   - **paper**: the paper in which the chunk is located

2. Run the evaluation:

   ```bash
   npm run evaluate
   ```

   This outputs two metrics:

   - **Precision**
   - **MRR** (Mean Reciprocal Rank)
